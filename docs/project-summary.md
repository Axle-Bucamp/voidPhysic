# 🌌 Void Physics Life Simulation - Project Summary

## Overview

The Void Physics Life Simulation is a 3D particle physics simulation that explores the emergence of matter, atoms, and complex structures from a primordial void. This simulation implements a novel "void physics" hypothesis where spacetime, matter, and time emerge from a topological void through iterative particle creation and bonding.

## Installation and Usage

### Easy Installation
```bash
git clone <repository-url>
cd void-physic
uv sync  # or pip install -r requirements.txt
```

### Simple Usage
```bash
cd examples
uv run python void_physics_life_game.py
```

### Programmatic Usage
```python
from void_physics_life_game import UniverseConfig, Universe

config = UniverseConfig(seed=123)
universe = Universe(config)

for i in range(100):
    universe.update()

stats = universe.get_state_summary()
print(f"Final state: {stats}")
```
